# CatTap 🐱

A mobile-first browser game designed for cats to tap and chase on a touchscreen. Works entirely as static files on GitHub Pages — no backend required.

## How to Play

Open the game on a tablet or phone, place it in front of your cat, and watch them chase the moving prey!

- **Laser Mode**: A red dot moves across the screen with smooth, enticing patterns.
- **Bug Mode**: A colorful bug with animated legs scurries around.
- Tap the prey to score a catch — enjoy burst animations, optional sound, and haptic feedback.

## Features

- 🎯 Generous tap/hit detection for paws
- ✨ Trailing sparkle effects behind prey
- 🏃 Natural movement: bursts, pauses, jitter, curved arcs, hide-and-peek
- 🔒 Lock UI mode (hold 3 fingers for 2 seconds) to prevent accidental settings changes
- ⚙️ Settings: difficulty, trail intensity, background theme, target size, sound, vibration, timer
- ⏱️ Optional 60-second session timer or endless mode
- 📱 Works on iPad, iPhone, and Android tablets

## Running Locally

Simply open `index.html` in a browser — no build step required.

## Deployment

Push to GitHub and enable GitHub Pages from the repository settings. The game will be available at `https://<username>.github.io/CatTap/`.
